# 🎁 Amigo Secreto dos Messias

Bem-vindo ao sistema simples de sorteio de **Amigo Secreto Online dos Messias**!  
Aqui você insere os participantes e o programa faz o sorteio garantindo que ninguém tire a si mesmo.

---

## 🚀 Como usar

1. Abra o arquivo **index.html** no navegador.
2. Preencha a lista de participantes indicando:
   - Nome
   - Telefone (opcional)
3. Clique em **Sortear**.
4. O sistema gera automaticamente:
   - A lista de pares (quem tirou quem)
   - A mensagem individual para enviar no WhatsApp
